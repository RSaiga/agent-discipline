# cycle — リストが尽きるまで内側のループを回す / Run the loop until the list is done

`red.md`・`green.md`・`refactor.md`・`commit.md` を、項目ごとに順に実行する。段階の境界は越えるが、各段階の規律は緩めない。
`config.yaml` の `commit` が `on-request` なら、この入口を呼んだことがコミットの依頼にあたる。
Runs the stage procedures in order, per item. Crosses stage boundaries only; every stage keeps its rules.

## 始める前 / Before the loop

最初の往復で、`discipline.md`・`tdd.md`・この手順・各段階の手順と設定をまとめて読む（`discipline.md` の「まとめて行う」）。
次の往復で、リストと `tdd.rules` の規約を読み、`git status` を見る。どれもループの中で読み直さない。

1. **リストを確かめる**（`tdd.md`「テストのリスト」）。無い・書けない → 止まる。二重ループの形 → 今の版では回せないので、段階ごとの入口（`ad-accept` から）を案内して止まる。全部終わっている → 緑を確かめて「完了」と伝えて止まる。
2. **最初が緑であることを確かめる。** リストが触る範囲の `fast` のスイートを全体で走らせる。`tdd.known_failures` に名前のある失敗だけを除き、
   それ以外が落ちていれば、何が落ちているかを報告して**止まる**（直すのはこのループの仕事ではない）。
   作業と関係のない差分が作業ツリーにあれば、それも報告して止まる。
   Start green: run the fast suites; anything failing that is not a named known failure means stop.
3. **走らせ方を 1 行で宣言する**（どのスイートを毎回全体で、どれを絞って走らせるか）。ループの中ではそれに従い、測り直さない。

## ループ / The loop

未着手が無くなるまで、**1 項目ずつ**:

1. **red** — `red.md`。
2. **green** — `green.md`。
3. **コミット（振る舞い）** — `commit.md`。`feat` か `fix`。直前の green の結果を緑の確かめに使い、`slow` の全体はループのあとで 1 回にする。
4. **refactor** — `refactor.md`。直すものが無ければ何もしない。
5. **コミット（リファクタ）** — 4 で変えたときだけ。`refactor`。空のコミットを作らない。
6. **次の項目へ。** 前の項目の気づきを持ち越さない。

## 止まる条件 / When to stop

どれかに当たったら、その場でループを抜けて報告する。避けて進めない。
- リストを書けない。最初が緑でない。作業と関係のない差分がある。
- red: 出典が無い・読めない・実際と食い違う。直しても意図した理由で落ちない。
- green: テストが間違っていると判断した。大きな構造の変更が要る。1 つの責務に収まらない。**既存のテストが落ち、リストに載っていない。**
- refactor: 振る舞いや期待値を変えないと直せない。バグを見つけた。
- コミット: 赤のまま。フックが落ちる。触っていないファイルを切り分けられない。
- 同じ項目で 2 周しても進まない。

## 抜けたら / After the loop

理由を問わず、触った範囲のスイートを（`slow` も）全体で走らせる。赤ならコミットを取り消さず、どの変更が原因かを報告して止まる。

## 報告 / Report

冒頭に走らせ方の宣言を 1 行。項目ごとに 1 ブロック:
```
[<i>/<n>] <振る舞い>
  red:      <テスト名> → FAIL（<理由>） / 出典: <どこから>
  green:    <触ったファイル> → PASS
  commit:   <hash> <件名>
  refactor: <直した構造 or「直すものなし」>（commit があれば hash）
```
最後に必ず:
```
完了: <n> 件 / 残り: <m> 件（止まった項目が [~] のままか [ ] に戻したか）
コミット: <hash と件名>
全体の実行: <コマンドと結果>
止まった理由: <止まる条件のどれか。回しきったなら「リストが尽きた」>
```
