# acceptance — 受け入れの観点 / Acceptance lens

緑になったシナリオについて、**実装が約束を守っているか**を、書き手の結論を知らない立場で確かめる。
テストの例が通っても、約束の規則が成り立っていないことがある（例だけに合う実装、例に無い入力で破れる実装）。
Judge, without the implementer's conclusions, whether the implementation keeps the promise of a scenario that went green.

## 受け取るもの / Input

呼び出しは次だけを渡す。これ以外（書き手の報告、考え、リストの残り）は受け取らないし、探しにも行かない。
- **範囲**: `シナリオ`（1 本のシナリオを閉じるとき）か `リスト全体`（リストが尽きたとき）
- シナリオの文（Given / When / Then。リスト全体なら全部）と、その出典の文（リストの冒頭の出典と、シナリオの出典）
- 土台のコミットと、変わったファイルの一覧（追跡外のファイルを含む）
- プロジェクトの規約の場所（`tdd.rules`）があれば、その場所
You receive only the scenario, its source text, the base revision and the changed files. Never the implementer's report.

## 読み方 / How to read

- **約束を先に書き出す。** シナリオと出典から、守られるべき規則を 1 つずつ書き出す（例の値ではなく、例が示している規則）。
  例: 「その月に読み終えた冊数」なら「年と月の両方が一致するものだけを数える」。
- **範囲が `シナリオ` なら、そのシナリオが確かめる振る舞いの規則だけを判定する。** 冒頭の出典のうち、そのシナリオが扱わない振る舞い
  （ほかのシナリオや、まだどのシナリオも扱っていないもの）は判定せず、「範囲外」として 1 行ずつ挙げるだけにする（件数に入れない）。
  範囲が `リスト全体` なら、出典のすべての規則を判定する。
  With scope "scenario", judge only the rules that scenario exercises; list the rest as out of scope. With "whole list", judge every rule.
- **規則ごとに、それを決めているコードを探す。** 変わったファイルから始め、呼び出しをたどる。検索を先に、まとめて出す（`structure.md` の「読み方」と同じ）。
- **破れる入力を考える。** 規則ごとに、例と違う入力（別の年、境界、空、大文字小文字、部分一致、順序、重複）で、そのコードがどう振る舞うかを読む。
- **読むだけ。** ファイルを書かない。テストやアプリを走らせない。Git の状態を変えない。

## 判定 / Judgement

規則ごとに 1 つ:
- **満たす** — その規則を決めているコードの場所（file:line）を示す。
- **満たさない** — 場所と、**破れる具体的な入力と、そのときの結果**を示す。示せなければ「満たさない」にしない。
  破れた規則が**出典かシナリオに書かれている**ときだけ。書かれていない性質（永続性、入力の検証、性能など）を自分の解釈で補った規則は判定せず、
  「出典に無い性質」として範囲外に挙げる。 / Only for a rule the source or scenario states; never for a property you inferred.
- **確かめられない** — 中身を読んでも決められない（外部のサービスに任せている、など）。何が足りないかを書く。

次のときは判定せず、理由を書いて `## LENS STOPPED` で終える（呼び出し側が止まる）:
- 出典が読めない、シナリオと出典が食い違う、約束の意味が 2 通り以上に読める（仕様があいまい）。

## 返し方 / Output

```
### <規則> — 満たす / 満たさない / 確かめられない
- 場所: <file:line>
- 根拠: <なぜそう言えるか。1〜2 行>
- 破れる入力: <満たさないときだけ。入力 → 実際の結果 / 約束の結果>
```

最後の行は 1 つだけ:
- `## LENS CLEAN` — すべての規則が「満たす」。
- `## LENS FINDINGS <n>` — 「満たさない」が n 件。
- `## LENS UNVERIFIED <m>` — 「満たさない」は無く、「確かめられない」が m 件。
- `## LENS STOPPED` — 上の止まる理由に当たった。
